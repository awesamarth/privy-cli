## Designed for agents

Every command works the same way:

<Steps>

1. **Discover**: `privy cli search "your task"` finds the right command.
2. **Schema**: `privy schema <command>` shows inputs, required confirmations and how the result is verified.
3. **Preview**: `--dry-run` validates offline, and `--diff` shows the change against your live app without writing.
4. **Execute**: `--yes` plus any confirmations the command needs. Nothing changes without them.
5. **Verify**: the CLI reads the change back and tells you what it confirmed.

</Steps>

Output is JSON by default, guides work offline with `privy docs`, and secrets only ever go through stdin.

## Use it with your agent

Install the skill so Claude Code, Codex, Cursor and other agents know when and how to use the CLI:

```sh
npx skills add awesamarth/privy-cli
```

Then ask: *"Use the Privy CLI to create an app called my-new-test and enable Google login."* You'll only need to log in yourself.

## FAQ

### What is Privy CLI?

Privy CLI is an unofficial command-line tool for managing Privy accounts and apps. It covers what you'd otherwise click through in the Privy dashboard: creating apps, login methods and OAuth providers, users, wallets, policies, webhooks, API credentials, team members and analytics. Output is JSON, so AI agents and scripts can use it too.

### How do I install Privy CLI?

Run `npm install -g @awesamarth/privy-cli`, or the Bun, pnpm or Yarn equivalent. It needs Node.js 22.18 or later. Then run `privy auth login`: you complete a browser CAPTCHA and type the email code Privy sends you. The session is stored in your OS credential store, such as the macOS Keychain.

### Is Privy CLI official?

No. Privy CLI is an independent, open-source (MIT) project, not an official Privy product. It uses the same endpoints as the Privy dashboard, most of which are undocumented, so a dashboard change can occasionally break a command until the CLI is updated.

### How is Privy CLI different from Privy's agent wallet CLI?

Privy's official [`@privy-io/agent-wallet-cli`](https://www.npmjs.com/package/@privy-io/agent-wallet-cli) gives an AI agent its own wallet to fund and transact with. Privy CLI manages your Privy developer account and apps instead: configuration, users, policies, webhooks and so on. It never signs transactions or moves funds.

### Can AI agents use Privy CLI?

Yes, it's built for them. Agents find commands with `privy cli search`, read their inputs with `privy schema`, preview changes with `--dry-run` or `--diff`, and apply them with `--yes`. Install the skill with `npx skills add awesamarth/privy-cli`. A human only needs to complete login.
